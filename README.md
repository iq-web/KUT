# ERASE — مساحة جديدة للأفكار

موقع عربي/إنجليزي للقرطاسية ومستلزمات الأعمال، مبني بـ React وTypeScript وVite.
الأسعار غير موجودة في كتالوج العملاء؛ يجمع الزائر المنتجات والكميات ويرسل طلب عرض سعر.

## نشر الموقع مجاناً على GitHub Pages

المشروع يحتوي على GitHub Actions workflow يبني الموقع وينشره تلقائياً عند رفع التغييرات إلى `main` أو `master`.

1. أنشئ مستودعاً عاماً جديداً على GitHub.
2. ارفع **محتويات هذا المجلد** إلى المستودع، وتأكد من تضمين مجلد `.github/workflows`.
3. في GitHub افتح **Settings → Pages**، واختر **GitHub Actions** كمصدر للنشر.
4. افتح تبويب **Actions** وانتظر انتهاء مهمة **Deploy ERASE site to GitHub Pages** بنجاح.
5. يظهر رابط الموقع في **Settings → Pages** أو في تفاصيل عملية النشر ضمن **Actions**.

المسارات الداخلية تستخدم عنواناً مع `#` عند النشر حتى تعمل صفحات المنتجات والإدارة على GitHub Pages، التي لا توفر إعداد إعادة توجيه تلقائي للمسارات. عنوان الموقع يكون عادةً `https://اسم-المستخدم.github.io/اسم-المستودع/`. إذا كان اسم المستودع `اسم-المستخدم.github.io`، يكون العنوان `https://اسم-المستخدم.github.io/`.

## تشغيل المشروع

### تشغيل سريع على Windows

1. نزّل وثبّت إصدار Node.js طويل الدعم (LTS) من [nodejs.org](https://nodejs.org/) إذا لم يكن مثبتاً.
2. انقر نقراً مزدوجاً على `START-WINDOWS.bat`.
3. يفتح الموقع على `http://localhost:5174`. اترك نافذة التشغيل مفتوحة أثناء استخدام المعاينة.

### تشغيل يدوي

1. نزّل وثبّت إصدار Node.js طويل الدعم (LTS) من [nodejs.org](https://nodejs.org/).
2. افتح مجلد `erase urt` في Visual Studio Code.
3. من القائمة اختر **Terminal → New Terminal**.
4. ثبّت الحزم:

   ```powershell
   npm install
   ```

5. شغّل الموقع:

   ```powershell
   npm run dev
   ```

6. افتح العنوان الذي يظهر في الطرفية، غالباً `http://localhost:5173`.
   إذا كان المنفذ مستخدماً، يختار Vite منفذاً آخر ويطبع عنوانه.
7. لفحص نسخة الإنتاج:

   ```powershell
   npm run build
   npm run preview
   ```

لإنشاء ملفات نسخة الإنتاج فقط على Windows استخدم `npm.cmd install` ثم `npm.cmd run build`. تحفظ الملفات الناتجة في مجلد `dist`.

## لوحة الإدارة التجريبية

- افتح `/admin/login` ثم اختر **دخول المعاينة**.
- أدر المنتجات والفئات والعلامات والعروض والطلبات والعملاء والإعدادات والنسخ الاحتياطي.
- البيانات في هذه النسخة محفوظة في `localStorage` على المتصفح والجهاز الحاليين فقط.
- وضع المعاينة **ليس تسجيل دخول آمناً**، ولا يشارك البيانات بين الأجهزة. لا تنشره كلوحة إدارة حقيقية قبل ربط خدمة مصادقة وخادم/قاعدة بيانات مع صلاحيات مناسبة.
- يمكن تنزيل نسخة JSON من صفحة **النسخ الاحتياطي والبيانات**. استيراد نسخة يستبدل بيانات المتصفح الحالية.

## تجهيز بيانات الشركة

من **لوحة الإدارة → الإعدادات** حدّث:

- رقم WhatsApp الدولي مع رمز الدولة (مثال شكل الرقم فقط: `+9647XXXXXXXXX`).
- الهاتف والبريد والعنوان وروابط الشبكات وساعات العمل.
- العناوين والوصف الظاهرين في الصفحة الرئيسية.

أضف صور المنتجات وروابطها وبياناتها من إدارة المنتجات. المنتجات والفئات الموجودة عند التشغيل بيانات توضيحية بعلامة `DEMO` في رموز المنتجات؛ استبدلها بالبيانات والصور المعتمدة قبل النشر. لا توجد أسعار أو بيانات عملاء أو أرقام مبيعات مخترعة.

## الطلب عبر WhatsApp

تُحفظ تفاصيل الطلب في سجل الإدارة المحلي، ثم يُفتح WhatsApp برسالة مشفّرة تحتوي اسم كل منتج وكميته وSKU والرابط الفعلي لصفحة المنتج، إضافةً إلى بيانات العميل والملاحظات. يلزم إعداد رقم WhatsApp أولاً. الإرسال النهائي يتم من العميل داخل WhatsApp.

## ملفات البيانات والاستبدال بقاعدة بيانات

- الأنواع: `src/types.ts`
- بيانات المعاينة والإعدادات الافتراضية: `src/data.ts`
- عقد مزود البيانات ونسخة التخزين المحلية: `src/dataAdapter.ts`
- سياق البيانات وحالات التحميل والحفظ: `src/store.tsx`
- الطلبات المؤقتة قبل الإرسال: `src/App.tsx` (مفتاح مستقل في التخزين المحلي)

يمكن استبدال المزود بطبقة API أو Supabase مع إبقاء واجهات المنتجات والطلبات متصلة بعقد البيانات في `types.ts`. عند الربط الفعلي، خزّن الطلب مع نسخ الاسم وSKU والرابط/slug والكمية وقت الطلب، وطبّق التحقق والصلاحيات على الخادم. لا تضع كلمات مرور أو مفاتيح خدمة في واجهة المتصفح.

## قبل نشر الموقع

1. استبدل بيانات وصور Demo ببيانات ERASE الحقيقية.
2. اضبط رقم WhatsApp وبيانات التواصل واسم الشركة.
3. حدّث `homeUrl` في الإعدادات إلى النطاق الرسمي، واستبدل روابط `example.com` في `index.html` و`public/robots.txt` و`public/sitemap.xml`.
4. أضف مصادقة حقيقية وقاعدة بيانات مشتركة وقواعد صلاحيات للوحة الإدارة.
5. شغّل `npm run build` واختبر روابط الموقع وWhatsApp على النطاق المنشور.

```text
erase urt/
├── public/                 # favicon وmanifest وrobots وsitemap
├── src/
│   ├── App.tsx             # صفحات العملاء والإدارة ومسارات الموقع
│   ├── data.ts             # بيانات العرض التوضيحي
│   ├── i18n.ts             # نصوص العربية والإنجليزية
│   ├── main.tsx            # نقطة تشغيل React
│   ├── store.tsx           # مزود البيانات والتخزين المحلي
│   ├── styles.css          # الهوية والتجاوب والحركة
│   └── types.ts            # نماذج البيانات
├── index.html
├── package.json
└── vite.config.ts
```
